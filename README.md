# Piatto Privat

Wochenplan, Einkaufsliste und Preisschätzung als Web-App für iPhone und Android.

**App öffnen:** https://gtown751.github.io/piatto/

## Auf dem iPhone installieren
1. Link oben in Safari öffnen.
2. Auf „Teilen“ tippen, dann „Zum Home-Bildschirm“.

Die App läuft danach im Vollbild und auch offline. Deine Daten bleiben auf deinem Gerät gespeichert.
